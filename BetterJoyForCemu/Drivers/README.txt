Windows x64 发布包内含 ViGEmBusSetup_x64.msi 1.17.333.0，

BetterJoy Direct prompts before launching the installer. Windows then requests
administrator approval through UAC. The driver is never installed silently.

BetterJoy Direct 会在启动安装程序前征求同意，随后由 Windows 通过 UAC
请求管理员权限。驱动绝不会静默安装。

ViGEmBus has been retired and its repository is read-only. This installer is
included for compatibility with BetterJoy Direct; it is not maintained here.

ViGEmBus 已停止维护且仓库为只读。本安装程序仅为 BetterJoy Direct
兼容性而附带，本项目不维护或重新签名该内核驱动。
